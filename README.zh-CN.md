# 科普视频制作工作流

简体中文 · [English](README.md)

一个可复用的 Codex Skill，将核心问题推进为资料核查、自然口播稿、视频成片、封面、中英文 YouTube 上传包和章节切片，也能读取进度后接续已有单期。

它从实际中文科普项目的制作流程提炼而来。技能正文和制作模板使用中文，仓库另提供完整中英文介绍。

**已去掉小云角色动画制作。** 小云仍可通过纯声音提问，科学原理图解和解释动效继续保留。

## 覆盖的制作步骤

| 步骤 | 主要交付 |
|---|---|
| 0 建档 | 单期目录规范、设置、制作进度、有效版本和确认依据 |
| 1 研究 | 核心问题、解释链、关键主张与来源边界 |
| 2 口播分镜 | 自然问答稿、分开的台词/制作提示、分镜及具体录制稿确认 |
| 3 配音与素材 | 已授权配音、解释图解、已下载查看的实拍、许可记录及选段预览 |
| 用户录制 | 用户录制；代理登记原片与录制稿依据 |
| 4 粗剪 | 完整保留有效表达，去错去重，先做好便于试听的真人响度 |
| 5 最终时间轴 | 实测配音、问答、章节黑幕、按帧核算的画面覆盖 |
| 6 精剪验收 | 无口播硬字幕母版、按需独立字幕、技术/画面/听核分项记录 |
| 7 封面 | 本期确定的比例和语言组合，仅最终PNG |
| 8 长片上传包 | 繁体标题、完整说明、章节、Tags/Hashtags和设置建议，另备英文标题及完整说明 |
| 9 章节切片 | 实际视频逐条对应文案、统一系列主线及真实长片观看路径 |
| 10 归档 | 独立可用的最终保留包，及须明确确认的精确清理清单 |

## 保留下来的关键规则

- **录制前备足相关实拍**，完成下载、查看、许可登记，交选段预览并留余量。静态图片不充实拍覆盖。
- 原片、粗剪、最终成片三类时间分开；字幕和上传章节从当前最终轴派生。
- 沿用来源项目的可覆盖风格默认值：实拍插镜 `R≥35%`、`R+D≤65%`，D为有效解释动效；R恰为35%时D=30%，R超过35%时D可低于30%。按主体信息互斥分类、最终帧数精确计算。这是项目约定，不是平台要求。
- 主母版默认无口播硬字幕；按需独立字幕采用 `.zh_CN.srt`、`.zh_TW.srt`、`.en_US.srt`，版本号放在语言后缀前。
- 完整解码、响度数字、实际画面、逐切口试听和连续全片听核分别验收；没检查就标待核。
- 上传包是独立必交产物，只有字幕不算发布准备完成。
- 制作期间保留原片和旧版本；清理须先确认精确文件与目录清单，已上传不代表准许删除。

## 本地安装

只复制仓库中的 [`science-video-workflow/`](science-video-workflow/) 文件夹，保留目录名，放到下列任一位置：

- 项目内使用：`<你的项目>/.agents/skills/science-video-workflow/`
- 用户范围使用：`~/.agents/skills/science-video-workflow/`

目标文件夹下应直接有 `SKILL.md`。新建目录先遵守目标工作区的规则，存在同名技能时不要直接覆盖。Codex会自动发现本地技能，未显示时重启。安装与发现方式依据 [OpenAI官方技能文档](https://learn.chatgpt.com/docs/build-skills)，核对日期为2026-10-31。

也可以请内置 skill-installer 从 [cjs5525/-science-video-workflow-skill](https://github.com/cjs5525/-science-video-workflow-skill) 安装 `science-video-workflow` 子目录。

## 使用示例

启动新一期：

```text
使用 $science-video-workflow 制作一期“卫星为什么会掉下来”的科普视频。从研究开始，按阶段自检推进，告诉我当前到哪一步。保留小云语音问答，不制作角色动画。
```

接续已有一期：

```text
使用 $science-video-workflow 继续这一期。先读单期AGENTS.md和制作进度.md，核对当前文件及有效确认，从最早未完成的必要依赖继续。
```

只需提供核心问题、已有稿件或原片路径。代理维护制作记录，不要求用户先整理转录稿或剪切区间表。

## 使用条件与边界

这是制作规程与模板，不是内置全部功能的视频剪辑软件。实际制作仍需相应的研究、转录、媒体检查、渲染工具，以及按需使用的TTS或图像服务。优先复用已有工具和授权；缺少能力时说明实际缺口，不能虚报完成。

包中不含密钥、付费账号、媒体、品牌资产、私有音色配置或本机路径。配音授权不自动包含原始录制外发转录。本技能不安装全局依赖、不改密钥或CI/CD设置、不自动公开发布、不静默删除文件。

不制作角色口型、呼吸、手势、出镜窗口、透明角色视频或角色合成；已有角色资产不会被擅自删除。以后要加角色动画，需要另定范围。
