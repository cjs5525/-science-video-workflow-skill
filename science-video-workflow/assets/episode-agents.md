# 〈单期主题〉目录规范

由代理在建档时填入当期选择，不要求用户填写表单。本文件复制为单期 `AGENTS.md` 后先完成配置再制作。

## 范围与结构

- 根目录：本规范、`制作进度.md`、`选题与结构-vN.md`、`资料核查-vN.md`、`口播稿-vN.md`、适用时的`小云台词-vN.md`、`分镜与动效规划-vN.md`。
- `素材/`：只读原始录制与本期下载素材；保留原文件名。
- `素材/edit/`：按需放`audio/`配音、`animations/`解释图解、`roughcut-vN/`粗剪、`timeline-vN/`最终轴、`finishing-vN/`合成验收及成片。
- `封面/`：最终PNG和交付清单。
- `发布包/`：独立字幕、长片上传文案、素材许可及最终章节摘要、总交付入口。
- `切片/`：最终章节片段、逐条Shorts文案与核对记录。
- 新子目录先写适用于其用途的规则；已有目录和用户文件不为套模板搬迁。

## 当期选择

| 项目 | 实际选择/待定项 |
|---|---|
| 核心问题、受众、平台 | 〈填写〉 |
| 视频画幅、尺寸、帧率 | 〈候选16:9/1920×1080；帧率接收原片后核定〉 |
| 主持人、第二声音 | 〈问答/单人；第二声音只配音，不制作角色动画〉 |
| 录制稿与确认依据 | 〈真实版本/待确认〉 |
| 配音配置、授权与现有工具 | 〈非敏感配置位置；不抄入密钥〉 |
| 公共素材库、Logo、转折音 | 〈真实路径及来源/许可状态〉 |
| R/D风格 | 〈默认R≥35%、R+D≤65%；R=35%时D=30%；R>35%可降低D〉 |
| 字幕与封面 | 〈字幕语种；封面比例×语言/数量〉 |
| 上传文案 | 〈默认繁体中文全套＋英文标题/完整说明〉 |
| 章节切片 | 〈需要/不适用及依据〉 |

## 版本与保护

制作期间原片、原定稿和历史媒体只读保留，修订另存vN。原片/粗剪/成片时间分开；稳定台词和章节ID不重编。上传和公开分别记录。任何删除均须精确文件/目录清单确认；密钥、系统配置、全局依赖、推送与公开发布遵守用户本地红线。

## 验证

文档检查存在、标题、编号和有效链接；视频检查实际编码文件、最终帧轴、完整解码、实拍/动效互斥覆盖、实际画面和音频。技术、抽帧、逐切口听核、全片检查分项记录；未检查不写通过。第8步必交项真实非空，字幕不能替代上传包。
