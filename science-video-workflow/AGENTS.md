# 技能包结构约定

本目录可直接复制到 Codex 的技能目录，目录名须保持 `science-video-workflow`。

- `LICENSE`：仓库已选MIT许可证的原文副本，随独立安装包保留。
- `SKILL.md`：触发说明、核心约束、阶段路由及完成标准。
- `agents/`：仅放 `openai.yaml`，提供技能展示元数据；不声明未经确认的服务依赖。
- `references/`：按阶段拆分的研究写稿、媒体制作、发布准备与归档参考；文件名使用英文小写和连字符。
- `assets/`：供新单期复制、再填入实际数据的 Markdown 模板；模板不是已完成交付。
- 上述子目录由本规范预先定义，创建前无需另加重复规范；生成单期仍须先写单期及其新子目录规则。

保留语音问答，不制作小云角色动画或角色叠层。科学解释动效与角色动画须明确区分。公共包不依赖原工作区、本机路径或其他未安装技能；运行时工具和许可不足时如实记录缺口。
