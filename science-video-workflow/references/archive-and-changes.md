# 第10步：归档、清理与变更依赖

## 触发与保留包

用户确认已上传，当前采用版本明确；有切片需求时第9步已完成或明确免除，才进入清理盘点。“已上传”不等于“已公开”，也不等于准许删除。

最终保留：

- 用户采用的最终长片、章节切片和明确需要的平台版本。
- 当前长片上传包、逐条Shorts上传文案。
- 最终选用的PNG封面。
- 一份脱离工程可用的总交付入口及验收摘要。
- 最终章节、轴/字幕版本、素材来源/作者/许可/必要凭证与未核边界。
- 实际需要的最终独立字幕。
- 必要目录规则、精简进度和一份清理清单/结果。

原始录制、用户后加文件和用途未知文件单独让用户决定，不能按命名或修改时间推断可删。公共素材、Logo、公共配置、密钥、全局依赖、其他单期及本技能包不在单期清理范围。为复用而跨项目引用的局部依赖也排除。

## 精确清单与执行

1. 只盘点本期，按保留/待删/待决定逐文件登记绝对路径、字节、修改时间、理由及关联当前版本；不跟随重解析点或符号链接。
2. 提取最终来源/许可和章节信息，确认保留包可独立使用，没有指向待删工程的必需依赖。对保留视频、PNG、字幕登记哈希、规格和可读性。
3. 从本轮候选及既有已确认清理记录推导“预计清理后为空/已经因清理而空”的目录，逐项列绝对路径、深度及依据。未知用途原本空目录不顺带清理。
4. 向用户提交**同一轮文件与目录精确清单**，说明当前第10步、预计空间、原片选择、实际恢复方式、删除后失去原工程精细返修能力及确认后动作。永久删除不能写成回收站；没有实际备份不承诺可恢复。
5. 获得对应版本清单的明确确认后，重新验证解析路径都在本期内、保留/待删无交集、大小/时间未变化、没有任务仍使用。出现新文件、变更或占用先跳过记录，不能扩大到通配符。
6. 同一原生文件操作环境逐项处理已确认文件；目录由深到浅，逐项重新解析路径和检查含隐藏项仍为空、非重解析点、非本期根目录或保留目录，**非递归删除单个空目录**。不得递归清空非空目录，不跨Shell拼接删除命令。
7. 记录文件/目录成功、失败、跳过数、实际文件字节与磁盘空间变化；复核保留哈希、媒体可读性、总入口及所有归档链接。遗留项未解决就不标全部完成。

这里只是操作规程，**不是删除授权**；仅生成清单不代表执行成功。旧清理许可不自动用于新文件或新一轮目录。

## 变更影响

| 修改 | 需复核或重新派生 |
|---|---|
| 主题、事实、数据 | 研究、脚本、对应图解、说明和封面结论 |
| 录制稿 | 纯TTS文本、配音、分镜及原片覆盖；录制确认状态 |
| 配音文本/配置 | 对应音频、问答时序、承接画面、最终轴及下游 |
| 台词、章节或转折时长 | 成片轴、实拍/动效放置与帧覆盖、字幕、发布章节、切片 |
| 画面/音量变化但片长不变 | 受影响媒体与验收；核对帧数、音轨和轴未变 |
| 仅独立字幕 | 对应字幕、语言、时序和入口；无字幕母版保留 |
| 仅上传文案/封面 | 对应文件与交付入口，不重剪已有视频 |

稳定ID不重排。候选另存vN，进度记录唯一有效入口及下游状态；上传后的历史文件是否保留由精确清单决定。
