# 第7—9步：封面、长片上传包与切片

## 第7步：封面

先记录本期比例×语言组合、张数和主封面。候选比例为4:3、3:4、16:9、9:16，按用途选择，不默认全比例多语。标题和视觉对应片内结论，未经证实的数字或地点不能做卖点。

先定主视觉，再逐比例逐语言调整构图，避免横图硬裁破坏竖图文字。检查繁体字形、英文拼写、断行及手机可读性。叠用户提供的真实Logo，检查安全区；缺资产先登记待输入，不伪造近似Logo。

最终只交PNG，记录尺寸、比例、语言、版本、平台用途和字节数。核对平台当前官方文件限制，过大先无损优化或按允许尺寸重导并复验，不默默改交JPG。原图/失败稿在制作中保留，到第10步列入精确待确认清单。

## 第8步：长片上传包

默认YouTube繁体中文主文案和英文标题/说明。若用户明确改变平台、语言或免除项目，记录依据后标不适用。当前元数据长度、章节条件、后台设置和合成内容披露等均查平台当期官方帮助，注明核对日期；不把源项目的频道习惯写成平台规则。

在实际文件中交付全部适用项，均可直接复制：

| 项目 | 内容与检查 |
|---|---|
| 繁体主标题 | 实际标题、字形、内容和平台长度 |
| 繁体完整说明 | 完整介绍、必要示意/预测边界、来源与许可署名，不是提纲 |
| 最终章节 | 当前母版/成片轴派生的时间戳与章名，顺序、片长及平台条件通过 |
| Tags / Hashtags | 后台关键词与话题标签分开，相关、语言及总长度符合要求 |
| 当期设置建议 | 实际音频语言、观众、类别、播放清单、许可、合成披露、评论、嵌入、可见性等适用项；未知写判断条件 |
| English title and full description | 两项均完整，说明含对应章节；与中文同义，不暗示有英文配音 |
| 总入口与进度 | 链接真实非空文件、版本与剩余事项 |

可合并在 `YouTube上传准备-vN.md`，也可分语言文件。繁体转换只针对文案，不改写真实文件路径。字幕、封面语言另定，英文文案不意味着英文字幕或封面。

**防漏交**：字幕不替代上传包；任一未免除必交项缺失，第8步仍未完成。成片轴已足够时可先交上传文案，再单列封面/许可/终审待办；文案完成不等于所有发布条件已满足，也不等于已修改后台。未制作内容不承诺可用，不把待填链接放进复制正文。

公开发布由用户操作，或在另有明确授权且符合其本地规则时执行。本技能默认不登录后台修改设置，不自动上传或公开发布；用户反馈已上传和真正已公开分别记录，实际链接不猜测。

## 第9步：章节切片与Shorts

在长片发布准备后、清理前交付；本期明确不切片可记不适用。依据最终黑幕章节边界判断可独立表达的问题，核对首尾句和上下文，不把黑幕当所有Shorts的固定开头。

用户已有片段只读复用，不擅自重剪、变速、烧字幕、移动或改名。新产物放单期 `切片/`，先写规则；已有其他路径直接登记。每条记录真实文件、字节/哈希、实测时长/画幅/帧率、内容依据、对应章节和实际检查/听核范围，不从文件名序号猜内容。

查YouTube当前官方Shorts条件和元数据限制，记录来源与日期；不合条件标待调整，未经授权不重剪。技术符合不代表推荐、收益或素材权利已核清。

先构建本期统一系列：长片核心问题→各片独立子问题与价值→长片真实补充内容→可用观看路径。各片独立能看懂，不故意截断答案；给系列对照与建议顺序。

在 `切片/Shorts上传设置-繁体-vN.md` 中每个实际视频对应一组：

1. 文件/章节、独立问题、系列作用、长片补充看点。
2. 繁体标题，默认“独立钩子｜系列名 n/N #Shorts #主题”，2—3个相关Hashtag；连同编号和标签核总长度，过长先精简。标题放Hashtag是源频道默认习惯，用户可覆盖，并非平台强制。
3. 繁体完整说明：本片价值→与长片关系→真实补充看点→一条符合实际后台状态的观看行动。
4. 后台Tags，逗号分隔、不带#，不能用Hashtags代替。
5. 可选繁体置顶留言，用本片问题邀请交流，并承接长片。

首选各片“相关影片”绑定同一真实长片。核实功能权限、长片可见性及真实绑定状态；未绑定不写“点击相关影片”。按照当期官方规则核对说明/留言网址的可点击性，不拿普通URL充当已可用入口。只有长片已公开且频道能找到时才建议“到频道影片页找〈实际片名〉”；条件未知单列待办，不虚构URL或已设置状态。

验收实际N个视频=N组文案，逐条查语言、标题含标签总长、Tags、内容、系列主线、补充看点、观看路径及本地链接；仅文案修订另存vN，不改媒体。切片字幕使用局部轴与规定语言后缀，不沿用长片绝对时间。

最终切片和Shorts文案都是第10步保留项。进度与总入口链接到当前文件；平台绑定未核时写待办，不能宣称推广链路已就绪。
