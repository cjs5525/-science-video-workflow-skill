# 第3—6步：配音、素材与成片

## 第3步：录制前供给

### 配音

有第二声音时复用用户已确认的非敏感配置和现有调用实现，不依赖特定厂商、音色或本机目录。不得把原项目的授权、接口数值和密钥自动带到新环境；数值不能跨工具当等效语速或分贝。

按实际授权生成纯台词TTS，文本、情绪参数分开。记录台词ID、稿件/配置版本、实际时长、脱敏调用结果、文本覆盖与听核状态。同文本同配置优先复用，失败不盲目重试计费。核对数字、专名、首尾音节；未试听标待核。单人旁白可记不适用。

本技能不生成小云角色画面，不接入角色母版，不制作口型/呼吸/手势或角色叠层视频。配音以独立音轨一次接入。

### 实拍、图片与解释动效

先查用户已有素材库，按主题选择真实相关的生活、情绪、风景或原理镜头。公共原文件不移动、不改名。需补充时优先正常检索 [Pexels中文站](https://www.pexels.com/zh-cn/)，按需要换合法来源；具体页面、API、缩略图、下载和本地文件阶段分开判断，不绕过登录、验证码、权限或速率限制。

下载并查看真实视频，逐项登记来源页、作者、下载/核对日期、许可及必要凭证/署名、人物品牌边界、核定状态和本地路径。用户提供素材不自动证明第三方权利全部核清；地点/日期不明只作示意，不冒充新闻实录。

**录制前供给验收**：按预计片长上限和章节准备足量不重复的实拍主选及余量。交素材选段预览、源视频入出点、逐段台词用途、预计R/D排布、图片独立清单。下载数量或原片总长度不代表可用覆盖；图片不能充实拍。供给不足继续第3步，不能只交动效后等待真人原片。

解释动效按机制选择动态图表、关系、过程、二维或2.5D等形式。复用可用工具；必要时做短样片验证中文字体、帧长、同步及实际导出。网页能预览不代表可稳定交付。精确数据图优先可校验的绘图，AI图像按适用范围使用，不冒充实拍。

每镜一重点；检查数值、曲线、图标语义、脚注、手机可读性、文字间距、进退场与声音。每项新动效至少查看实际编码视频的一张全尺寸信息完整帧和真实接缝，不只看缩略联系表。避免全片只有弹入文字卡；画面不显示内部路径、工程ID或实现说明。

失败记录保留脱敏时间、域名/路径、状态码、响应类型及允许公开的错误摘要；不保存认证头或含凭据URL。403不直接证明密钥错误，原因未知就如实记录。网络故障不免除实拍供给与比例条件。

## 第4步：按稿粗剪

接收原片后登记文件名、大小、修改时间、录制稿版本、方向、帧率及镜像状态。保护原片；需要时只翻转真人一次，不能翻转合成文字和Logo。

逐句对照录制稿，选择完整、准确、自然的一次表达，不机械选择最后一次或最短一次。保留有意义的停顿和反应；去掉试说、重说、错误开头及无关交流。临时第二声音可在授权范围内替换为正式配音，但保留可用反应镜头。

每个YS单元登记脚本位置、实际表达、源入出点、保留次数、差异与疑点。原片ASR可能把试说重说压成一句；首次导出后重新逐句核对剪后音轨。出现词时长异常、相同起音或识别冲突时拆开两次起音并听原声，不以ID全覆盖、静帧或单一ASR证明无重复。数字或专名无法确认就听看原片；漏录/录错记录补录建议，不擅自合成主持人补话。

新录制条件可用60—90秒代表样片校准。**粗剪交付前**完成便于正常试听的真人响度、必要轻度均衡/清理/压缩与峰值保护；不把首次调声推到精剪。约−16 LUFS、真峰值≤−1.5 dBTP是源频道的起始参考，按本期实测调整，非平台硬性标准。

交付真人粗剪、保留决定、台词覆盖及疑点。技术通过与实际逐句听核分别记录。

## 第5步：统一最终时间轴

先测正式配音实际长度，再编排真人、完整配音、真实反应、相关实拍/图解及章节；无角色出镜或动嘴窗口。缺少承接镜头时优先现有相关实拍/图解和真实同机位反应，不默认循环、定格、变速真人或剪短TTS补齐。确需补录或改变表达时提供具体选择。

章节采用纯黑底、居中白色主题标题，不显示P编号、照片、Logo或技术页脚。转折音使用用户提供或明确批准的素材，测量实际时长和响度，不擅自拉伸或遮盖词尾/起音。缺素材时先推进独立工作并标待接入，不把依赖它的最终轴标通过。

原片、粗剪、成片三类时间分开，映射至少有：片段ID、源类型/文件、源入出、粗剪入出、成片入出、台词/章/图解ID、镜像状态及变更原因。配音和章节卡使用独立源类型。

锁定明确版本，记录用户确认或已授权范围内的内部锁定。随后字幕、发布章节、插镜及覆盖表均从该版本派生。

### 按帧核算R/D

令N为成片总帧数，R和D为按主要信息载体分类、左闭右开区间 `[start,end)` 的各自并集帧数：

- `R >= ceil(35*N/100)`；`R+D <= floor(65*N/100)`。
- 比较精确整数：`100*R > 35*N` 时D允许低于30%；`100*R == 35*N` 时要求 `100*D == 30*N`。不按显示小数的四舍五入判定。
- R与D的有效区间必须互斥；同类重叠先取并集。实拍为底、解释动画主导信息时只计D。
- R只计相关、已查看且承担主体画面的实拍B-roll；主持主镜头、AI画面、照片、章节黑幕及动画都不计R。
- D须以过程、关系、对比、机制或变化推动解释。普通字幕、Logo、转场、静态图推拉、装饰、无信息长停留与循环不计D。
- 记录每段ID、成片入出帧、类别、视觉任务、来源许可、质量与排重结果。不能用无关长镜头、重复/循环或慢放凑数。未接入成片的独立媒体不计。

示例：N=1000，R=350、D=300满足边界；R=351、D=200也满足；R=350、D=200不满足特殊边界；R=400、D=300超过合计上限。示例只解释规则，不是实际成片证据。

## 第6步：精剪、字幕与验收

按最终轴完成真人方向、必要画面处理、音轨、解释图解、实拍和用户提供的Logo。自然保留皮肤纹理，保护头发/肩部/手部/转头；背景虚化及其他明显效果沿用本期已确认样片，缺少确认时先给代表对照，不承诺跨工具参数同效。实拍等比例裁切铺满，不拉伸、不漏边，默认关闭其原声。

真人粗剪声音为混音基线，分别测量并匹配第二声音感知响度，再协调音乐和转折，避免双重增益和同一TTS重复播放。整句处理后分回片段保持样本长度与位置不变。

所有音频切口听核前后至少1秒，并结合完整句，检查词尾、邻句残音、配音首尾、爆点和双重音轨。短淡化防爆点，不能掩盖残留语音。至少一次连续全片检查；未实际听核明确列成片时间与待验项。

主母版默认无口播硬字幕，必要图解文字和章节标题保留。按需字幕从实际成片音频生成、脚本纠错，不补入没说出的台词。命名：

- `字幕-主题-vN.zh_CN.srt`
- `字幕-主题-vN.zh_TW.srt`
- `字幕-主题-vN.en_US.srt`

检查UTF-8、语言/后缀、条目顺序、入出时序、片长范围及有效链接；繁转、地区润色、英文翻译分别记录。烧录版若另需，保留无字幕母版。

验收分开记录：规格/流/完整解码、时间轴与同步、实际画面、按帧覆盖、逐切口听核、配音完整听核、连续观看/听核、字幕与文档链接。导出后的编码成品再复核实际画面和比例，不能只验工程预览。结果填 [交付模板](../assets/delivery.md)，未核项不写通过。
