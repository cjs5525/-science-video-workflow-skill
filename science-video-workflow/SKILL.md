# 科普视频制作工作流

将一个核心问题或已有录制接续为可交付的科普视频项目。主持人负责解释，第二声音可承担观众追问；本技能沿用“小云”作为语音角色称呼，不要求使用该名称或特定音色。

## 首次进入与续作

1. 先读目标工作区及单期 `AGENTS.md`、当前进度和真实交付文件。明确当前有效版本与确认依据，不因聊天结束、文件名最新或风格认可推定阶段完成。
2. 新单期先写目录规则，再创建内容。用 [单期规范模板](assets/episode-agents.md)、[进度模板](assets/progress.md) 建档；有现成结构则沿用，不为套模板搬迁旧文件。
3. 用户只需给核心问题、已有稿件或原片路径。代理负责整理、转录和内容定位，不把转录稿、剪切区间表当用户前置作业。
4. 核定平台、预计片长、画幅、角色/语音模式、现有工具及素材库、封面和语言需求。缺项先标待定；只询问会影响后续结果的关键选择，同时继续独立工作。
5. 复用已有有效授权，普通步骤自检后连续推进。录制稿确认绑定具体版本；公开发布和精确清理范围另行取得明确授权。

## 范围与默认值

- **去除小云角色动画制作**：不创建、修复或要求角色母版、口型、呼吸、眼睛/手势动画、透明角色视频、出镜窗口或角色画面合成。遇到已有项目角色素材只登记现状，不擅自删除。用户另外要求角色动画时，说明超出此技能范围并另行确定方案。
- 小云可作为纯声音参与问答；发言时使用相关实拍、解释图解或自然反应镜头，不预留角色动画位置。单人旁白项目可将第二声音标为不适用。
- **科学解释图解动效保留**。动态图表、机制演示和关系变化与角色动画是不同制作任务。
- 交付候选为 16:9、1920×1080；接收原片后核定帧率、方向及是否镜像。主母版默认无口播硬字幕，图解说明与黑幕章名保留。
- 封面按期选择比例、语言和数量，只交最终 PNG；频道 Logo 由用户提供，不复刻近似品牌图案。
- YouTube 默认繁体中文标题、完整说明、最终章节、Tags/Hashtags、设置建议，另交英文标题与完整说明。字幕语言与封面语言分别决定。
- 延续来源项目的实拍/动效比例作为本技能默认风格，**并非平台要求**：R≥35%，R+D≤65%；R>35%时D可低于30%；R恰为35%时D=30%。用户明确改动时记录覆盖值和影响，不默默放宽。
- 工具按现有能力选择。本技能是制作规程与模板，不自带转录、TTS、素材账号、渲染器或完整自动剪辑引擎；缺少工具时明确可完成部分和具体阻塞。

## 阶段路由

只在进入相关阶段时读取对应参考。续作从最早未完成的必要依赖开始，不重复研究或重做已确认成品。

| 步骤 | 交付与转入条件 | 进入时读取 |
|---|---|---|
| 0 建档 | 目录规则、当期配置、进度、有效确认和输入清楚 | 本文件及模板 |
| 1 选题研究 | 核心问题→问题链；关键主张可追溯至来源与适用边界 | [研究与口播](references/research-and-script.md) |
| 2 口播分镜 | 自然问答录制稿、纯TTS文本、分镜与预计R/D；用户确认具体录制稿 | 同上 |
| 3 配音与素材 | 已授权TTS、解释动效；录制前备足已下载、可查看、登记许可的相关实拍，附选段预览和余量 | [媒体制作](references/media-production.md) |
| 用户录制 | 接收只读原片，登记录制稿依据、镜像及方向 | 同上 |
| 4 内容粗剪 | 按实际录制稿逐句保留完整表达，去重去错；真人响度先达到便于试听的程度 | 同上 |
| 5 最终时间轴 | 真人、完整配音、反应和章节统一编排；锁定成片轴并按帧核算R/D | 同上 |
| 6 精剪验收 | 无口播硬字幕母版、按需独立字幕；技术、画面、听核分别有证据 | 同上；[交付模板](assets/delivery.md) |
| 7 封面 | 本期确定的比例/语言组合，最终PNG，文字和Logo检查 | [封面与发布](references/publishing.md) |
| 8 长片上传包 | 繁体标题/完整说明/章节/Tags/Hashtags/设置建议＋英文标题/完整说明，实际非空文件和有效入口 | 同上 |
| 9 切片与Shorts | 实际视频一一对应逐条文案、系列主线、长片补充价值及真实观看路径；不需要时记不适用 | 同上 |
| 10 上传后归档 | 用户确认已上传后先盘点保留/待删/待决定；精确清单确认后才执行清理 | [归档与变更](references/archive-and-changes.md) |

第3步素材准备在用户录制前完成；用户提前录制也不免除这道供给检查。最终放置、字幕与发布章节均由第5—6步的有效成片轴派生。

## 状态、证据与交付

- 使用“未开始／制作中／待输入／待确认／产物完成待验收／验收通过／有遗留问题／不适用”，写明日期、文件版本、证据范围和下一动作。
- 原片时间、粗剪时间、最终成片时间分开记录，片段映射保留来源。P章、YS主持台词、XY第二声音、R图解的稳定ID不随排序重编；R图解ID与实拍覆盖类别R是不同字段。
- 每次进度报告说明第几步、已完成、正在处理和下一步；需要确认时额外说明此次对象/版本及确认后做什么。
- 原片、旧定稿和旧媒体在制作期间只读保留，修订另存vN；不能以清理模板代替具体删除授权。密钥不进包、不进日志；外发真人录制与调用TTS的授权分开判断。
- 图表预览不等于编码视频通过，完整解码/响度数字不等于听感通过。未实际检查就标待核，不虚构试听、许可、平台绑定或公开状态。
- 更新单期进度与唯一总交付入口。[交付模板](assets/delivery.md) 只填真实文件；缺少未免除的上传文案项不能标第8步完成。章节切片和上传后清理分别记录状态。
